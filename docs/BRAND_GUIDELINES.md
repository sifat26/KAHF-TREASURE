# Brand Identity

KAHF TREASURE is a premium alcohol-free attar brand inspired by Islamic elegance, Arabian heritage, and timeless luxury.

The website must feel authentic, calm, refined, and trustworthy.

The experience should communicate quality before price.

Avoid anything that feels like an AI-generated landing page.

# Gold Usage

Gold is an accent.

Never use bright yellow.

Never use shiny gradients.

Never cover large sections in gold.

Use gold for:

• Buttons
• Borders
• Small highlights
• Icons
• Section labels
